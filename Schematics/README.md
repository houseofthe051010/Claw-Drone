# Claw Drone Schematics


* `Drone/drone.kicad_sch` - aircraft power, flight stack, ESP32 CRSF bridge, claw servos, and FPV camera system
* `Controller/controller.kicad_sch` - Black Pill Pico-compatible controller board, controller ESP32, UART link, joysticks, buttons, and ILI9341/XPT2046 display
